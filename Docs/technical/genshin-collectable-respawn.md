## 一、刷新机制总览（先分清 4 种模型）

原神采集物并不是统一的“每天刷新”，而是至少存在 4 种不同的刷新模型。判断某个素材的 CD，先要确定它属于哪一种：

| 模型 | 计时起点 | 是否受每日 4:00 重置影响 | 典型对象 |
| --- | --- | --- | --- |
| ① 采集后计时（相对刷新） | 从“你采走它的那一刻”开始倒计时 | 否 | 区域特产、多数植物 / 食材、晶蝶 |
| ② 每日 4:00 固定重置 | 服务器每日 04:00 | 是 | 魔物、地脉花、盗宝团、部分调查点 |
| ③ 矿石固定日期刷新 | 服务器每日 00:00 判定，按矿点固有周期 | 否（按日期周期） | 铁 / 白铁 / 水晶 / 紫晶 / 魔晶 / 星银等锻造矿 |
| ④ 每周重置 | 每周一 04:00 | 是 | 周本 BOSS 奖励 |

> 关键结论：**只有模型 ② 和 ④ 与“凌晨 4 点”有关**。区域特产、植物、晶蝶、矿石都不能按“每天 4 点刷新”来理解。

### 4.8 版本的重要变更
- 官方 4.8 更新说明原文：**“部分采集的刷新时间由 48 小时调整为 46 小时”**。
- BWIKI 明确：**区域特产的刷新时间由 48 小时改为 46 小时**。
- 4.8 同时把世界 BOSS 的“复生时间”由 5 分钟调整为 **10 秒**（需传送离开再返回才会刷新）。

## 二、区域特产（Local Specialty）—— **46 小时**

**CD 规律：① 采集后计时**（不是每日刷新）。
- 从你采集的那一刻起算，**46 小时**后原地重新长出（4.8 之前为 48 小时）。
- 与服务器每日 4:00 重置**无关**。
- 每个节点坐标固定，不进宝箱、不可购买，只能野外采、尘歌壶种植（部分）或任务 / 活动一次性获得。
- 联机去好友世界采集**不会**影响对方自己的刷新倒计时。
- 一个角色 1→90 级满突破共需 **168 个**对应特产。

## 三、通用食材 / 植物类采集物

**CD 规律：① 采集后计时**。按刷新时长分档：

| 刷新时长 | 代表采集物 | 说明 |
| --- | --- | --- |
| **12 小时** | 甜甜花、薄荷、蝴蝶翅膀（捕蝴蝶）、树莓 | 半日即可复采，适合一天跑两趟 |
| **24 小时（1 天）** | 蘑菇、松果、树上的水果（苹果 / 日落果）、马尾、胡萝卜、白萝卜、小麦 | 最常见的野外食材刷新周期 |
| **46 小时**（4.8 前为 48 小时） | 冰雾花（花朵）、烈焰花（花蕊）、莲蓬 | 与特产同档，随 4.8 调整 |
| **24 小时** | 琥牢山一带的琥珀 | 固定点位，约 1 天 |
| **一次性** | 宝箱、岩之印调查、多数摩拉盒 | 拾取后永久消失 |

> 说明：上述为通用规律，个别素材（尤其后期新增区域）可能不完全一致；蘑菇类还受“须弥草种子 / 特定天气”等条件影响。
> **蝴蝶翅膀**（捕蝴蝶）与**晶核**（捕晶蝶）是两种不同生物素材，刷新规律也不同，见第五章。

## 四、矿物 / 矿石类

**CD 规律：③ 矿石固定日期刷新**（2.0 版本起）。
- 刷新时间点固定为**服务器每日 00:00**，与“你几点挖的”无关。
- 每个矿点有自己**固有**的刷新日期，按等级周期循环；延迟挖掘不会改变刷新日。
- 铁匠处可消耗体力标记**魔晶矿**点位。
- 带**凝光**（或其它显示矿物的角色）可让小地图显示矿点。

| 矿石 | 等级（精锻对应） | 刷新周期 | 备注 |
| --- | --- | --- | --- |
| 铁块 | 一级（精锻用杂矿） | **1 天** | 最常见 |
| 白铁块 | 二级（精锻用良矿） | **2 天** | |
| 星银矿石 | 二级（精锻用良矿） | **2 天** | 龙脊雪山 |
| 水晶块 | 三级（精锻用魔矿） | **3 天** | 蒙德 / 璃月 |
| 紫晶块 | 三级（精锻用魔矿） | **3 天** | 稻妻 |
| 魔晶块 | 三级（精锻用魔矿） | **3 天** | 需体力标记，每日可采一轮 |
| 萃凝晶 | 三级（精锻用魔矿） | **3 天** | 枫丹 |
| 虹滴晶 | 三级（精锻用魔矿） | **3 天** | 后期区域新增矿 |
| 电气水晶 | 非锻造矿（炼金素材） | **约 1 天** | 资料有 1 天 / 2 天两种说法，实测偏 1 天 |
| 石珀 / 夜泊石 / 清水玉 | —— | **46 小时** | 实为**璃月区域特产**，见第二章 |

> 补充：铁矿、白铁块、水晶块共享铁匠处“锻造经验类素材”的每日上限（约 30 万经验，折合约 120 个水晶矿）。

## 五、晶蝶 / 晶核 与 蝴蝶翅膀

| 素材 | 来源 | 刷新规律 | 备注 |
| --- | --- | --- | --- |
| 晶核 | 捕捉**晶蝶** | **每日 04:00 重置（模型②）** | 下雨天部分晶蝶（如岩晶蝶）不出现，可调时间跳过雨天 |
| 蝴蝶翅膀 | 捕捉**蝴蝶** | **约 12 小时（模型①）** | 与晶蝶不是同一种生物 |

> 关于晶蝶存在两种说法：多数资料为“**每日凌晨 4 点刷新**”，也有早期资料称“12 小时”。当前以**每日 4:00 重置**为准；若未抓到而飞走，可通过“传送离开再返回”让它重新出现（同一批未捕完前不会因传送而补满）。

## 六、鱼类（钓鱼点）—— **72 小时**

**CD 规律：① 采集后计时（3 天）**。
- 把某个钓鱼点的鱼**钓空后**，该点在 **3 天（72 小时）**内不会补充，钓完即空。
- **昼夜分池机制**：同一钓点不同时段出现的鱼不同，需要切换时间才能钓干净。
  - **全天**：鳉鱼类、炮鲀类
  - **白天 12:00–18:00**：蝶鱼类（如流纹茶蝶鱼）
  - **夜晚 18:00–06:00**：棘鱼类、假龙类
  - **例外**：赤魔王只在白天；踏鞴砂沉船的**雷鸣仙**只在晚上
- 判断是否钓空：水面平静=已钓完；仍有波纹=还有鱼（可能因分池未刷出，需调时间）。

## 七、木材 —— 特殊机制

| 项目 | 规则 |
| --- | --- |
| 获取方式 | 用单手剑 / 长枪角色砍伐对应树木（荒泷一斗天赋可额外获得） |
| 刷新机制 | 按“**每砍伐约 10 棵触发一次刷新循环**”，可在密集点循环砍伐 |
| 每日上限 | 每种木材每日约 **2000 份**（不同资料略有差异） |
| 便利道具 | 须弥声望 3 级解锁「**王树瑞佑**」，可一次性采集周围树木 |

> 木材属于“资源上限 + 循环刷新”机制，与其它采集物的“采集后计时”不同。

## 九、★ 独立处理：圣遗物调查点（Artifact Investigation Points）

圣遗物狗粮主要来自大世界的“调查点”，其规律与采集物不同，单独说明：

| 项目 | 规则 |
| --- | --- |
| 每日调查次数上限 | 所有常规调查点**共用 100 次 / 日** |
| 达到上限后的表现 | 已加载区域内的光点仍可继续拾取；但一旦**传送 / 切换场景 / 重登 / 断网重连**，全图光点会隐藏，直到**次日 04:00** 才重置 |
| 单个调查点刷新 | **24 小时**（最常见）/ **12 小时**（较少）/ **每日 04:00 重置**（极少）/ **一次性** |
| 圣遗物掉落 | 1 星 / 2 星圣遗物（约 2:1），可分解为祝圣精华或直接摧毁换摩拉 |
| 不占 100 次上限的点位 | 摩拉盒、水面漂浮小木箱（多为**一次性**）、须弥沙漠**风滚草**（击破掉落，随机） |

> 结论：跑圣遗物路线时，**优先捡圣遗物点，避开只给摩拉微粒 / 武器 / 矿石的干扰点**，并注意 100 次额度在传送后会“清零刷新”。

## 十、★ 独立处理：魔物（怪物）

**CD 规律：② 每日 04:00 重置**（绝大多数）。

| 对象 | 刷新 / 重置规律 | 备注 |
| --- | --- | --- |
| 普通怪 / 精英怪（丘丘人、愚人众、遗迹机关、盗宝团等） | **每日 04:00 重置** | 掉落普通怪物素材 |
| 每日击杀计数 | 普通怪 + 精英怪合计**上限 400 只** | 超过上限后击杀不再掉落任何经验 / 摩拉 / 素材 |
| 世界 BOSS（无相系列、爆炎树、急冻树、纯水精灵、魔偶剑鬼、恒常机关阵列、翠翎恐蕈、掣电树、风蚀沙虫、吞星之鲸、正机之神等） | **复生 10 秒**（4.8 起，原 5 分钟），需**传送离开再返回**才刷新 | 领奖消耗树脂；不同 BOSS 掉落不同 |
| 地脉花（藏金之花 / 经验之花） | **每日 04:00 重置** | 消耗树脂领取 |
| 周本 BOSS（风魔龙、北风狼、公子、女士、雷电将军、散兵、若陀龙王等） | **每周一 04:00 重置** | 每周限领 1 次奖励（可用树脂追加） |
| 讨伐 / 悬赏委托 | 每周刷新 | 声望系统 |

> 注意：**地方传奇也占用上面“400 只击杀计数”**（见下章），所以打传奇前要留意当日击杀额度。

## 十一、★ 独立处理：地方传奇（Local Legend）

**CD 规律：② 每日刷新（现实第二天，约每日 04:00 后）**。
- 击败后需等到**现实时间第二天**才能再次挑战；粗略按“每天刷一次”理解。
- 每只地方传奇对应成就（含限定条件成就），击杀可获得角色经验、摩拉及对应怪物素材。
- **占用怪物击杀计数**：例如利亚姆视为精英怪、**一次占用 3 个击杀数**；若当日已接近 400 上限，击杀传奇可能**不掉落任何东西**。
- 传奇动物（如科西霍、「战羊」与「铁爪」、「蟹沙皇」）不掉经验 / 摩拉，只掉对应食材（兽肉 / 禽肉等）。

主要地方传奇清单（含版本）：4.0 枫丹（隐者王·多尔库、铁皮子爵、湖畔的维维安涅、湖畔的尼尼安涅、海原巡回法官、「渐渐隐去的老兵」、「深谷之剑」、「双生妖精骑士」）、深境螺旋系列（历经百战的火刃突击队员 / 执灯人 / 岩居蟹 / 浊水粉碎幻灵 / 浊水喷吐幻灵）、纳塔系列（异色三连星、巴拉奇科、科西霍、海浪中的莎孚、夜魂试炼等）。

## 十三、常见误区

| 误区 | 实际情况 |
| --- | --- |
| “所有采集物每天 4 点刷新” | 只有魔物、地脉花、盗宝团、部分调查点等按每日 4:00 重置；特产 / 植物 / 晶蝶 / 矿石都不是 |
| “特产每天都能采一轮” | 特产是 **46 小时**，隔天再跑往往白跑，节奏天然是“两天一轮” |
| “矿石也是采集后计时” | 2.0 后锻造矿改为**固定日期**（每日 00:00 判定），与挖掘时间无关 |
| “把矿点挖晚一点，就能让它晚点刷新” | 刷新日是该矿点**固有属性**，延迟挖掘不会改变 |
| “采好友世界的特产会消耗对方次数 / 影响对方刷新” | 不会；对方按自己的倒计时照常刷新，互采双赢 |
| “晶蝶和蝴蝶翅膀是一回事” | 晶蝶掉**晶核**（每日 4:00），蝴蝶掉**蝴蝶翅膀**（约 12 小时），是两种生物 |
| “圣遗物调查点和普通采集一样” | 调查点**共用每日 100 次**，且传送 / 切场景后会隐藏，直到次日 4:00 |
| “打地方传奇随时都能打” | 每日刷新一次，且**占用当日 400 只怪物击杀额度**，额度不足不掉落 |

## 十四、数据来源与不确定项

**来源**

1. 《原神》4.8 版本更新说明（官方）—— “部分采集的刷新时间由 48 小时调整为 46 小时”“首领敌人复生时间由 5 分钟调整为 10 秒”。
2. 《原神》BWIKI：特产页（46 小时 + 各区域特产清单）、地方传奇页（掉落次数 / 击杀计数）、晶核页。
3. 游民星空《地图各类资源刷新时间一览》《野外资源刷新时间一览》《钓鱼点刷新机制解析》。
4. 17173《资源刷新时间介绍》《须弥木材刷新机制》《电气水晶刷新周期》。
5. NGA《2.0 版本精锻用矿石刷新机制变化探索》（矿石固定日期 + 3 天周期）。

**不确定 / 需实测确认项**

- **电气水晶**：有“24 小时”与“2 天”两种资料，建议以 1 天为参考。
- **晶蝶**：主流为“每日 4:00”，早期资料称“12 小时”。
- **木材**：每日上限与“每 10 棵刷新循环”来自社区统计，具体数值可能随版本变化。
- **冰雾花 / 烈焰花 / 莲蓬**：官方 4.8 表述为“部分采集”，是否与特产同步为 46 小时建议以实测为准。
- 后期新增区域（纳塔 / 挪德卡莱 / 至冬）的个别素材刷新时间仍可能微调。
