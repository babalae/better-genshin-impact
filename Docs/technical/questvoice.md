# 自动配音

自动配音通过识别原神画面中的对白文字和人物姓名，将台词交给文字转语音（TTS）引擎朗读。适合在没有官方配音的支线、世界任务中使用，也可以为不同角色设置不同声音。

本功能需要用户主动启动。它复用 BetterGI 已有截图，不会另开截图器，不会替你选择对话选项，也不会自动等待语音播完再推进剧情。它不判断当前台词是否已有官方配音，也不会自动关闭游戏原声；有声对白中可能出现声音重叠。

本文适用于已经包含“自动配音”入口的版本。软件安装、游戏设置及截图方式请先参考官方[快速上手](https://www.bettergi.com/quickstart.html)。本页说明当前界面与使用步骤，不代表所有分辨率、引擎和游戏场景均已验证。

## 功能入口

左侧导航的“自动配音”下有四个子页面：

| 页面 | 用途 |
| --- | --- |
| 运行与日志 | 启动、停止配音，查看当前对白、角色、实际声线、处理阶段及错误，打开日志 |
| 配置与映射 | 选择默认引擎，设置 OCR，绑定旅行者、未知 NPC 和角色声线，管理路由文件 |
| GPT-SoVITS 配置 | 设置本地或远程 GPT-SoVITS 服务，管理 GPT 声线库，调整实验性流式开关 |
| 其他引擎设置 | 配置其余六种引擎，选择和试听声音，将声音加入通用声线库 |

切换页面不会停止已启动的配音会话，也不会丢弃正在编辑的草稿。有效修改会自动保存，但运行中的配音继续使用启动时的配置，修改在下次启动配音时生效。

## 使用前准备

1. 按官方快速上手配置原神和 BetterGI，确认软件已经能够取得游戏画面。建议先使用简体中文、常见的 16:9 分辨率及默认亮度，避免滤镜或遮挡对白的叠加层。
2. 在 BetterGI 启动页绑定原神并启动截图。自动配音借用这条截图管线，不能只启动配音而不启动宿主截图。
3. 准备兼容的 OCR 模型，并选择一个可用的语音引擎。OCR 和语音合成是两件事：使用系统语音或在线音色，也仍然需要 OCR 模型。
4. 如果启用了自动剧情，按需关闭快速跳过。对白显示时间过短时，可能来不及完成识别或合成。自动配音不会替你更改自动剧情配置，具体选项见官方[自动剧情与邀约](https://www.bettergi.com/feats/timer/skip.html)说明。

> 官方[分辨率支持](https://www.bettergi.com/feats/append/resolution.html)介绍的是各项功能的通用适配情况。自动配音的对白区域还会受到 UI 缩放、DPI 和特殊对话布局影响，不能据此认定所有比例都能正常识别。

### OCR 模型

在“配置与映射 → OCR 设置”中检查以下项目：

| 项目 | 说明 |
| --- | --- |
| OCR 模型路径 | 默认为程序目录下的 `User/QuestVoice/ocr/PP-OCRv6_rec_small.onnx`，也可通过“浏览”选择其他位置 |
| DirectML 设备序号 | 默认为 `0`，仅用于自动配音的专用 OCR，不修改全局 OCR 的设备配置 |
| 采样间隔 | 默认为 `150` 毫秒，可设置 `50～500` 毫秒；只决定从宿主已有帧中取样的间隔，不创建额外截图 |

需要使用带 `character` 字典的 PP-OCRv6 Rec ONNX 模型：字典为 18708 个字符，输入为 `x: N,3,48,W`。不能把其他通用 OCR 模型改名后直接使用。

是否附带该模型，以具体发行包说明为准。包内已经包含模型时，无需重复下载；没有包含时，先取得兼容模型，再放入上述路径或修改模型路径。程序会按需建立小型布局和路由示例，但不会自动下载 OCR 模型或配音权重。

专用 OCR 需要 DirectML。如果当前进程已加载不含 DirectML 的 CUDA、OpenVINO 等 ONNX 运行库，请在 BetterGI 硬件加速设置中切换到内置 CPU / DirectML，并重启软件。自动配音不会自行替换正在使用的全局运行库。

## 首次使用

下面以 Windows 系统语音为例，不需要先部署配音服务或准备角色权重。

1. 完成上面的游戏截图和 OCR 模型准备。
2. 打开“其他引擎设置”，在顶部下拉框选择“Windows 系统语音（SAPI）”。
3. 点击“刷新声音列表”，选择本机已经安装的声音。没有声音时，需要先安装支持 SAPI 的系统声音，再刷新列表。
4. 在“试听文本”中输入一小段文字，点击“试听当前引擎声音”。确认可以听到声音后再继续。
5. 打开“配置与映射”，把“默认 TTS 引擎”设为 Windows 系统语音。首次只想让所有角色使用同一种声音时，可以先关闭“启用角色声线路由”。
6. 打开“运行与日志”，点击“启动自动配音”，然后进入一段显示时间较长的游戏对白。
7. 观察“当前对白”“当前角色”“当前实际声线”和处理阶段。没有识别到内容或没有声音时，按下文的[常见问题](#常见问题)逐项检查。

不想使用系统语音时，也可以在“其他引擎设置”选择火山翻译预设音色，先试听，再到“配置与映射”选择它作为默认引擎。在线引擎依赖网络和服务可用性，不能用“选中了音色”代替实际试听。

> “其他引擎设置”顶部下拉框只切换正在编辑的引擎，不会改变默认配音引擎。正式配音的默认引擎始终在“配置与映射”中选择。

## 运行与日志

页面提供“启动自动配音”“停止配音与播放”“校验配置”三个运行控制按钮。

正常处理会经过以下阶段：

```text
对话界面检测 → OCR 识别 → 角色识别 → 声线路由 → TTS 合成 → 音频播放
```

“当前处理内容”显示正在处理的对白和实际使用的角色声线；“最近事件”保留近期关键反馈。需要完整信息时，使用“打开 BetterGI 日志”或“打开日志目录”。悬浮日志只显示简短状态，较详细的诊断在文件日志中。

“校验配置”执行文件和路由静态检查，不代表已经完成模型推理、服务合成或声卡播放。当前页面尚未显示独立的静态校验摘要，不能把点击后没有提示当作检查通过；请结合“配置与映射”里的“校验草稿”、引擎试听，以及启动时的具体错误判断。

运行中不要反复快速切换启动和停止。修改设置后，应先停止并等待当前操作结束，再重新启动。试听和正式配音共用播放与服务资源，不能同时执行。

## 选择语音引擎

| 引擎 | 使用前需要准备 | 声音配置 | 播放方式 |
| --- | --- | --- | --- |
| GPT-SoVITS | 自行运行兼容的 `api_v2` 服务，以及 GPT / SoVITS 权重和参考音频 | 在 GPT 声线库中建立声线，再绑定给角色或默认 NPC | 完整合成；可选实验性按句流式 |
| 火山翻译 | 可访问对应在线服务的网络 | 三种中文预设音色 | 完整合成后播放 |
| Windows 系统语音（SAPI） | 本机已安装支持 SAPI 的声音 | 刷新并选择系统声音 | 完整合成后播放，可离线使用 |
| VOICEVOX | 自行运行的 VOICEVOX 引擎和声音库 | 刷新声音 / 风格，或填写 Style ID | 完整合成后播放 |
| vits-simple-api | 自行运行的兼容服务和模型 | 选择服务声音，或填写 `VITS:0`、`BERT-VITS2:0` 等 ID | 完整合成后播放 |
| OpenAI 兼容语音 API | 服务地址、服务端可用的模型和声音，必要时填写 Key | 选择本地建议或手填 Voice ID | 完整合成后播放 |
| Google Translate TTS | 可访问对应在线服务的网络 | 选择语言和正常 / 慢速 | 分段合成，接收并合并后播放 |

程序不会安装上述外部引擎、自动下载配音权重或把本机模型上传到远端。请按各引擎和声音的使用条件准备资源。

### 其他引擎的通用操作

1. 在“其他引擎设置”选择要配置的引擎。
2. 有服务地址的引擎，填写本地 / 默认 Base URL；需要远程服务时，填写远程地址并选择“使用远程实例”。两处地址分别保留。
3. 选择声音，填写该引擎实际支持的参数，再通过“试听当前引擎声音”验证。
4. 要让这个声音出现在角色声线下拉框中，填写“通用声线显示名”，点击“加入通用声线库”。不填写显示名时，会使用当前声音名称。
5. 回到“配置与映射”完成角色或默认规则绑定。仅加入声线库不会自动替换默认 NPC 或某个角色的声线。

“此引擎的通用声线”中可以选择已加入的条目，修改名称或声音 ID，也可以删除不再使用的条目。仍被旅行者、角色、NPC 或旁白规则引用的声线不能直接删除，需要先解除引用。

VOICEVOX 和 VITS 的服务端声音列表需要主动点击刷新；其他引擎的本地预设或系统声音列表也可能在进入页面、修改模型时自动加载。Google 的语言列表使用本地预设。能列出声音不等于已经验证合成，仍需试听。

#### 火山翻译

选择中文预设音色即可，不需要本地模型、账号或 Key。该功能使用非公开客户端接口，没有稳定性或限流承诺；正式配音会向该服务发送待朗读台词，试听会发送试听文本。网络错误或服务拒绝时，可以稍后重试或切换引擎。

#### Windows 系统语音（SAPI）

刷新并选择已安装的声音，速度倍率范围为 `0.5～2`。系统能够用于其他软件的某种声音，不一定已暴露为 SAPI 声音；列表为空时应检查安装与兼容性，而不是填写别人的声音标识。

#### VOICEVOX

默认本地地址为 `http://127.0.0.1:50021/`，以实际服务端口为准。刷新后选择声音 / 风格，或填写非负整数 Style ID。支持速度倍率 `0.5～2`、音高 `-0.15～0.15`。声音的使用条款与署名要求由相应声音库规定。

#### vits-simple-api

默认本地地址为 `http://127.0.0.1:23456/`。当前适配 VITS 和 BERT-VITS2 的文本合成，声音 ID 由模型类型和编号组成。根据服务要求填写可选 API Key，选择语言和 `0.5～2` 的速度倍率。

这里的语言选项控制配音服务，不会自动使游戏画面识别支持相同语言。其他 VITS 模型类型不能仅凭服务端存在就认定本客户端已经支持。

#### OpenAI 兼容语音 API

填写服务要求的完整 Base URL，保留必要的路径前缀，例如 `https://服务器/v1/`。再填写服务端当前可用的模型、Voice ID，以及服务要求的 API Key。

界面中的模型和声音示例只是输入建议，不代表服务当前支持它们；自建兼容服务可以填写自定义 ID。支持 WAV、MP3，以及按 24 kHz、单声道、16 位 PCM 解释的 PCM 响应，速度倍率范围为 `0.25～4`。地址格式检查不等于认证成功，需用试听确认。

#### Google Translate TTS

选择预设语言，速度为 `1`（正常）或 `0.5`（慢速）。这是网页 TTS 接口，不是 Google Cloud TTS 的服务承诺；需要网络可达，服务可能拒绝请求。分段接收不等于增量播放，当前仍在完整音频准备好之后播放。

## GPT-SoVITS 配置

### 连接服务

先自行启动兼容的 GPT-SoVITS `api_v2` HTTP 服务，再打开“GPT-SoVITS 配置 → 服务连接”。本地默认地址为 `http://127.0.0.1:9880/`，应以实际启动参数为准。

需要远程实例时，开启“使用远程实例（本地与远程地址独立保留）”，填写远程 API URL。支持带路径前缀的反向代理地址；URL 不能内嵌用户名、密码、查询令牌或片段。

点击“测试连接”只检查服务可达性，不会合成台词、切换权重，也不能证明后端空闲。连接 / 请求 / 合成超时是所有引擎共享的设置：连接范围 `1～120` 秒，请求和合成范围 `1～600` 秒；合成默认 `180` 秒。

### 建立声线

1. 展开“GPT-SoVITS 声线库”，点击“新增声线”。
2. 在声线下拉框中选中要编辑的声线配置（Profile），填写便于识别的显示名称。修改显示名称不会改变角色对这个声线的引用。
3. 选择服务实例。留空时沿用 GPT 当前选择的实例；明确选择本地或远程，可以固定该声线所使用的实例。
4. 填写 GPT 权重 `.ckpt`、SoVITS 权重 `.pth`、参考音频，以及与参考音频逐字对应的中文“参考台词”。本地实例可使用页面中的浏览按钮选文件。
5. 等待状态显示有效配置已保存。新建但资源不完整的 Profile 会留在草稿中，不能把它当作已经保存成功。
6. 输入“试听文本”，点击“试听选中声线”。需要中断时点击“取消试听”。

资源只在当前选中的 Profile 中维护。要修改某个角色的 GPT 资源，先找到它绑定的声线，再到这里编辑，不需要给每个默认规则重复填一套权重。

本地 Profile 的相对资源路径以路由 JSON 所在目录为基准。远程 Profile 的权重、参考音频必须已经存在于服务器，填写服务器能够访问的路径；客户端不会上传文件，也不会用本机的同名路径代替服务器路径。

### 把 GPT 声线用于正式配音

新建声线后，还要完成绑定：

1. 打开“配置与映射”，将“默认 TTS 引擎”设为 GPT-SoVITS。
2. 开启“启用角色声线路由”。
3. 在“未知 NPC 与旁白 → 默认 NPC 声线”中明确选择刚建立的 GPT Profile，作为未匹配角色的回退声音。
4. 按需为旅行者和已知角色指定声线，等有效修改自动保存，再启动配音。

> 只创建 GPT Profile、只选择默认引擎，或关闭角色路由，都不会自动把这个 Profile 设为默认声音。关闭路由时仍沿用配置中的旧默认声音字段；新配置不一定已有这些资源。首次通过声线库配置 GPT 时，请开启路由并明确指定默认 NPC Profile，避免出现默认资源为空的错误。

### 实验性流式配音

在“合成与流式设置”中开启“按句流式合成与增量播放（关闭时完整合成）”，停止后重新启动配音才会生效。默认关闭，需要后端支持当前 `api_v2` 按句流式协议；其他引擎不会因为打开这个开关就变成流式播放。

当前 GPT 协议固定中文文本、中文参考语言、`cut5` 切分和 WAV，不提供此页面未展示的语速或其他流式模式。试听始终完整接收后播放，不能用试听来证明正式流式播放正常。

完整模式会在新句音频准备好后再替换旧句；流式模式会等待新句有足够的有效音频再接替。缺料或断流时可能停止本句，已经播出的片段不能撤回，也不会自动重新合成并拼接。出现问题时，先停止，关闭流式开关，再使用完整模式排查。

## 角色、旅行者和默认声音

声线是“如何合成声音”的配置，角色是“识别到谁时使用哪条声线”的规则。多个角色可以共用一条声线，也可以在同一份路由目录中引用不同引擎。

### 默认规则

- 关闭“启用角色声线路由”时，所有对白使用所选引擎的默认声音。
- 开启路由后，明确的角色绑定优先；没有可用专属声音并按缺失策略回退时，先使用明确指定的“默认 NPC 声线”。它可以是另一种引擎的 Profile，不受默认引擎选择覆盖。
- 没有明确指定默认 NPC Profile 时，兜底声音才沿用“默认 TTS 引擎”的默认配置。
- 下拉框中的“使用默认配音规则”表示没有单独指定 Profile，不等于自动选择列表第一项。

### 旅行者

在“旅行者 → 游戏内名称”填写画面中会出现的昵称，有多个历史昵称时一行一个；在“使用声线”中选择已准备好的 Profile。

昵称用于 OCR 匹配，不会修改游戏内名称。不要填入其他角色已有的姓名、别名或纠错名，否则目录校验会拒绝冲突。角色管理中空、荧仍可以有各自的身份和声线；选择旅行者的声音不等于为所有提到“旅行者”的文本自动判定性别。

### 已知角色

展开“角色管理”，搜索角色 ID、名称、别名或 OCR 纠错名。选中条目后可以编辑：

| 字段 | 作用 |
| --- | --- |
| 角色 ID | 清单内部的唯一标识，不能与其他角色冲突 |
| 正式名称（Names） | 画面中的正式姓名，一行一个，至少填写一项 |
| 别名（Aliases） | 同一角色可能出现的其他名称 |
| OCR 纠错名（Corrections） | 将确定的姓名误识别结果归到这个角色，不修改对白正文 |
| 角色声线（VoiceId） | 从已经准备好的声线中选择；留空表示没有专用声线 |

使用“新增角色”添加条目，使用“删除选中角色”移除不需要的条目。识别姓名时会依次尝试正式名称、别名和纠错名，不会因为名称相似就随意替换角色。

在“高级路由目录与缺失策略”中，`Fallback` 表示已知角色未绑定或资源不可用时尝试回退，`Fail` 表示对相应缺失报错。未知 NPC 使用通用回退不等于配置出了错；应先准备一个可用的默认 NPC 声线。

### 旁白

“旁白声线”可以保存一个独立映射，但当前实时对白链路尚未传入明确的旁白上下文，尚未接通自动旁白路由。不能依靠这一项让无姓名栏对白自动切换到旁白声线。

姓名 OCR 失败也不等于旁白。排查无姓名画面的声音时，先查看实际命中的声线和默认 NPC 回退，不要仅凭姓名为空判断路由结果。

## 自动保存与生效时间

当前界面使用自动保存，不需要寻找单独的保存按钮。输入内容进入草稿、成功写入文件、应用到下一轮配音，是三个不同时间点。

| 修改内容 | 写盘方式 | 配音何时使用 |
| --- | --- | --- |
| 默认引擎、OCR 设置、连接及各引擎普通参数 | 由 BetterGI 自动保存，将约 500 ms 窗口内的改动合并写入；URL 需先通过格式检查 | 下次启动配音或新发起的试听 |
| 角色、旅行者昵称、默认规则绑定、声线 Profile 及资源 | 输入停顿 750 ms 后校验，只有有效草稿才会自动保存 | 下次启动配音；试听按所选引擎或当前 Profile 草稿执行 |

750 ms 是安排校验和保存的防抖时间，不是写盘一定完成的时限。请以页面的保存状态为准，例如“已保存 · 下次启动配音生效”。切换声线、引擎编辑对象或页面不会清空各条目的输入，也不会取消已经安排的有效修改保存；切页后仍可能写入磁盘。

以下情况不会直接覆盖已有有效文件：

- 新声线名称、声音 ID 或引用不完整。
- 新输入的本机 GPT 权重或参考音频路径不存在。
- 路由文件被其他程序修改，当前草稿的版本已经过期。
- 编辑过程中更改了路由文件路径，当前草稿仍属于旧目标。

已保存但暂时不可用的旧资源可以保留并显示诊断，不会静默换成第一条声线。保存期间继续输入时，较新的输入会再安排一次保存。

正常关闭窗口或从托盘退出时，程序会尝试提交文本输入并排空路由草稿；路由草稿校验或保存失败会阻止退出，保留窗口供修正。关闭到托盘只是隐藏窗口，不代表退出。无效 URL 只保留在编辑输入中，原有效地址仍保留，不保证阻止退出；请在关闭前修正。强制结束进程、系统强制关机或断电不能保证保存尚未完成的输入。

运行或试听期间，受保护的角色和资源编辑操作会被禁用。部分普通参数即使仍能编辑，也只会影响下次启动，不会修改正在合成的请求。

## 路由文件、导入和备份

“配置与映射 → 路由文件路径”决定当前使用的角色和声线清单，默认是程序目录下的 `User/QuestVoice/routing.json`。这里的“目录”指 JSON 清单，不是游戏目录或模型文件夹。

进入设置页时会按需准备并加载示例；示例没有配音权重，不代表其中角色已具备专属声音。已有布局和配置不会被示例覆盖。

展开“高级路由目录与缺失策略”可以执行：

| 操作 | 行为 |
| --- | --- |
| 加载配置 | 从当前路由文件读取清单；有未处理草稿时需先处理 |
| 新建空目录 | 当前目标文件不存在时，建立空的清单草稿；有效内容仍按自动保存机制处理 |
| 校验草稿 | 检查当前草稿结构、引擎和引用，不等于检查服务可达或实际完成合成 |
| 导入配置 | 读取选定 JSON，确认提示后，将有效内容自动保存到当前路由目标，并保留备份 |
| 导出草稿 | 将通过校验的草稿写到另一个 JSON，不替代当前文件的自动保存，也不自动清除当前未保存提示 |
| 放弃草稿并重新加载 | 明确丢弃尚未保存的输入，再读取当前目标；丢弃前会要求确认 |

> 导入会安排写入当前路由文件，不是只预览文件。先检查当前路由路径，再确认导入；需要保留现有配置时先备份。导出时也不能把目标选成当前路由文件。

成功保存会对原文件保留 `.bak` 备份，例如 `routing.json.bak`。这是保存时的旧文件备份，不代替用户自己的长期备份。

遇到“文件冲突”时，不要继续用旧草稿覆盖磁盘上的新配置。先导出能够通过校验的草稿，再重新加载并核对差异。准备切换路由文件路径时，也应先处理旧草稿；程序不会把旧输入自动写到新目标。

旧版 v1 路由清单可以继续读取，编辑并成功保存或导出后按 v2 写入，单纯加载不会升级。旧 v1 清单在普通引擎下沿用固定声音；需要通用角色映射时，先完成有效编辑并保存为 v2。旧 GPT 默认资源仍用于兼容已有配置，但当前界面通过声线库维护新 Profile，新用户应按上面的 GPT 绑定步骤配置。

## 停止与异常恢复

使用“停止配音与播放”请求结束当前会话。已经发给 GPT-SoVITS 的请求可能仍需排空，期间会显示停止中；取消本地播放不等于远端推理已经结束。请等待当前操作结束后再启动、试听或更改受保护的资源。

如果连接中断后出现“后端状态未知”，按以下顺序恢复：

1. 停止自动配音和试听。
2. 手动恢复或重启 GPT-SoVITS 服务，确认它已经可用。
3. 保存或处理未完成草稿，完全退出 BetterGI 后重新打开，再试听和启动配音。

当前界面没有独立的后端恢复确认按钮；仅重启远端服务不一定清除客户端已经记录的未知状态。退出 BetterGI 只关闭本地工作，不会替你关闭或重启外部 GPT 服务。

当前版本还存在一个已知边界：其他操作持锁、启动尚在排队时立即请求停止，可能出现界面已停止但后台仍在采样，而且停止按钮可能已不可用。避免连续快速启停；遇到时先处理未保存草稿，再从托盘完全退出 BetterGI 并重新启动，不要只关闭到托盘。本页更新不代表该竞态已修复。

## 常见问题

| 现象 | 建议检查 |
| --- | --- |
| 没有“自动配音”入口 | 确认当前发行版本确实包含该功能，不要把其他分支的界面说明套到当前安装包 |
| 试听正常，进游戏后没有识别 | 试听不依赖 OCR 和游戏截图；检查宿主是否已绑定并启动截图、模型是否匹配、游戏是否在前台以及对白是否显示足够久 |
| 提示模型缺失或缺少字典 | 检查 OCR 模型路径和兼容性，不要只改其他模型的文件名 |
| 提示当前运行库不含 DirectML | 切回内置 CPU / DirectML 后重启 BetterGI；只改专用设备序号不能补齐缺失的运行库 |
| GPT 声线能试听，正式启动却提示默认资源为空 | 检查是否启用了角色声线路由，以及默认 NPC 是否明确绑定到已建立的 GPT Profile |
| 改了引擎却仍用原来的声音 | 检查是否只切换了其他引擎页的编辑对象；明确绑定的 Profile 还会按自己的引擎播放，运行中的会话也不会热切换 |
| 角色没有使用专属声线 | 检查角色路由开关、识别姓名、Names / Aliases / Corrections、声线绑定、缺失策略，以及修改是否已保存并重新启动配音 |
| 无姓名画面没有使用旁白声线 | 当前实时管线尚未接通自动旁白路由；先查看默认 NPC 回退和实际路由结果 |
| 页面一直显示“等待输入有效配置” | 检查所有未完成的 Profile、名称、声音 ID、引用及新填写的本机路径，不要把停顿 750 ms 当作必然保存成功 |
| 提示文件冲突或路径已改变 | 导出有效草稿，重新加载对应文件并核对；不要直接覆盖他人的修改 |
| URL 输入没有保存 | 使用完整 HTTP/HTTPS 地址，保留服务要求的子路径，不要在 URL 中加入账号、密码、查询令牌或片段 |
| 在线引擎出现 TLS、超时、认证或限流错误 | 检查网络、服务地址及凭据；连接检测不等于合成成功。不要通过关闭证书校验来处理，可先换用本机系统语音排除网络因素 |
| 画面已换句，仍能听到上一句 | 新句在音频准备好后才接替，旧句可能继续播放；需要立即中止时使用停止，而不是继续快速切页或重复启动 |
| 运行中控件无法编辑 | 先停止正式配音和试听，等待排空完成后再编辑 |

## 配置文件

以下路径均相对于 BetterGI 程序目录；修改过路由文件路径时，以实际设置为准。

| 路径 | 内容 |
| --- | --- |
| `User/config.json` | 默认引擎、OCR、连接、超时及各引擎参数；可能包含本机路径、API Key 等私密信息 |
| `User/QuestVoice/routing.json` | 角色、昵称、默认规则和声线 Profile；可能引用本机或服务器上的权重与参考音频 |
| `User/QuestVoice/routing.json.bak` | 路由文件的旧内容备份，同样需要按私人配置处理 |
| `User/QuestVoice/ocr/` | 手动部署或发行包附带的专用 OCR 模型 |
| `User/QuestVoice/auto-scene.json`、`dialogue-one-line.xml` | 按需部署的场景和布局资源，不熟悉格式时不要随意改动 |
| `User/QuestVoice/cache/` | 当前实现的会话临时音频与 OCR 诊断，正常排空和释放后清理；异常退出可能留下文件 |
| `log/` | BetterGI 主日志，可能包含对白、识别结果、资源路径和错误信息 |

Key 在界面中遮罩显示，不代表配置文件已经加密。不要直接上传整个 `User` 目录、备份、参考录音或日志；反馈问题前先脱敏。使用在线引擎时，待合成文本会发送到相应服务；使用他人提供的模型、角色声音或服务时，应遵守相应使用条件。
