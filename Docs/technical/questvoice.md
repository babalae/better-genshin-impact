# 自动配音

自动配音通过识别原神画面中的对白文字和人物姓名，将台词交给文字转语音（TTS）引擎朗读。适合在没有官方配音的支线、世界任务中使用，也可以为不同角色设置不同声音。

它复用 BetterGI 已有截图，不会另开截图器，不会替你选择对话选项，也不会自动等待语音播完再推进剧情。它不判断当前台词是否已有官方配音，也不会自动关闭游戏原声；有声对白中可能出现声音重叠。

本文适用于“自动配音”位于“实时触发”页的版本。软件安装、游戏设置及截图方式请先参考官方[快速上手](https://www.bettergi.com/quickstart.html)。本页说明当前界面与使用步骤，不代表所有分辨率、引擎和游戏场景均已验证。

## 功能入口

自动配音在左侧导航“实时触发”页，位于“自动剧情”之后，是一张可展开的卡片：

| 位置 | 用途 |
| --- | --- |
| 卡片开关 | 打开后随截图器自动开始和停止，不需要另外点击启动 |
| 卡片展开内容 | 当前状态、处理进度、正在处理的对白和声线、最近事件；“设置…”“校验配置”“打开日志”“打开日志目录”按钮 |
| 设置窗口 · 引擎与声线 | 左侧列出 7 个引擎，★ 为默认引擎；右侧配置所选引擎的连接、声音、参数、声线和试听 |
| 设置窗口 · 角色 | 角色声线开关、默认 NPC 声线、旁白声线、旅行者、角色列表 |
| 设置窗口 · 识别 | OCR 说明、采样间隔 |
| 设置窗口 · 高级 | 网络超时、找不到角色声线时的处理、角色目录文件及其导入导出 |

### 什么时候运行

开关打开后，自动配音的启停周期与其他实时触发功能一致：

| 情况 | 自动配音 |
| --- | --- |
| 截图器启动 | 开始 |
| 一条龙、JS 脚本等独立任务运行中 | 停止，任务结束后自动恢复 |
| 暂停热键、战斗、传送、选择 F 选项期间 | 不识别画面，结束后继续 |
| 设置窗口打开期间 | 暂停，关闭窗口后按新设置继续 |
| 截图器停止、游戏退出 | 停止 |

未运行时，卡片状态会说明原因，例如“已关闭”“等待启动截图器”“独立任务运行中，已暂停”“设置窗口打开中，已暂停”。

## 使用前准备

1. 按官方快速上手配置原神和 BetterGI，确认软件已经能够取得游戏画面。建议先使用简体中文、常见的 16:9 分辨率及默认亮度，避免滤镜或遮挡对白的叠加层。
2. 在 BetterGI 启动页绑定原神并启动截图。自动配音借用这条截图管线，截图器没有启动时不会运行。
3. 选择一个可用的语音引擎。OCR 使用 BetterGI 内置模型，不需要另外准备。
4. 如果启用了自动剧情，按需关闭快速跳过。对白显示时间过短时，可能来不及完成识别或合成。自动配音不会替你更改自动剧情配置，具体选项见官方[自动剧情与邀约](https://www.bettergi.com/feats/timer/skip.html)说明。

> 官方[分辨率支持](https://www.bettergi.com/feats/append/resolution.html)介绍的是各项功能的通用适配情况。自动配音的对白区域还会受到 UI 缩放、DPI 和特殊对话布局影响，不能据此认定所有比例都能正常识别。

### OCR

自动配音使用 BetterGI 内置的 PP-OCRv6 识别模型，不需要下载或放置模型文件。推理设备跟随“设置 → 硬件加速”：

- “OCR 使用 CPU”开启（默认）时，配音的 OCR 在 CPU 上运行。
- 关闭“OCR 使用 CPU”后，按硬件加速选择的设备运行，CPU、DirectML、CUDA、OpenVINO 都可以使用。

“设置窗口 → 识别”中的采样间隔默认为 `150` 毫秒，可设置 `50～500` 毫秒。它只决定从截图器已有画面中取样的间隔，不会另外截图。识别偏慢时，可以先关闭“OCR 使用 CPU”改用显卡，再适当调大采样间隔。

## 首次使用

下面以 Windows 系统语音为例，不需要先部署配音服务或准备角色权重。

1. 完成上面的游戏截图准备。
2. 在“实时触发”页找到“自动配音”卡片，展开后点击“设置…”，打开设置窗口。
3. 在“引擎与声线”页左侧选择“Windows 系统语音（SAPI）”。
4. 点击“刷新声音列表”，选择本机已经安装的声音。没有声音时，需要先安装支持 SAPI 的系统声音，再刷新列表。
5. 在“试听文本”中输入一小段文字，点击“试听当前引擎声音”。确认可以听到声音后再继续。
6. 点击右上方的“设为默认引擎”，左侧列表中该引擎前出现 ★。首次只想让所有角色使用同一种声音时，可以在“角色”页关闭“启用角色声线”。
7. 关闭设置窗口，打开卡片开关。截图器已启动时，卡片状态变为运行中；然后进入一段显示时间较长的游戏对白。
8. 观察卡片中的当前对白、角色、实际声线和处理进度。没有识别到内容或没有声音时，按下文的[常见问题](#常见问题)逐项检查。

不想使用系统语音时，也可以选择火山翻译预设音色，先试听，再设为默认引擎。在线引擎依赖网络和服务可用性，不能用“选中了音色”代替实际试听。

> 在左侧列表中选择引擎只切换正在编辑的对象，不会改变默认引擎。正式配音的默认引擎是带 ★ 的那一个，用“设为默认引擎”更改。

## 卡片中的运行信息

正常处理会经过以下阶段，卡片用 6 个节点显示：

```text
对话界面 → OCR → 角色 → 声线 → 合成 → 播放
```

节点下方显示当前阶段的说明。“当前”一栏显示正在处理的角色、实际使用的声线、对白文字，以及合成和播放状态；“最近事件”保留最近 8 条关键反馈。需要完整信息时，使用“打开日志”或“打开日志目录”。悬浮日志只显示简短状态，较详细的诊断在文件日志中。

“校验配置”执行文件和路由的静态检查，结果显示在卡片状态区。它不代表已经完成模型推理、服务合成或声卡播放；请结合“高级”页的“校验”、引擎试听，以及启动时的具体错误判断。

## 选择语音引擎

| 引擎 | 使用前需要准备 | 声音配置 | 播放方式 |
| --- | --- | --- | --- |
| GPT-SoVITS | 自行运行兼容的 `api_v2` 服务，以及 GPT / SoVITS 权重和参考音频 | 新增声线并填写权重和参考音频，再分配给角色或默认 NPC | 完整合成；可选实验性按句流式 |
| 火山翻译 | 可访问对应在线服务的网络 | 三种中文预设音色 | 完整合成后播放 |
| Windows 系统语音（SAPI） | 本机已安装支持 SAPI 的声音 | 刷新并选择系统声音 | 完整合成后播放，可离线使用 |
| VOICEVOX | 自行运行的 VOICEVOX 引擎和声音库 | 刷新声音 / 风格，或填写 Style ID | 完整合成后播放 |
| vits-simple-api | 自行运行的兼容服务和模型 | 选择服务声音，或填写 `VITS:0`、`BERT-VITS2:0` 等 ID | 完整合成后播放 |
| OpenAI 兼容语音 API | 服务地址、服务端可用的模型和声音，必要时填写 Key | 选择本地建议或手填 Voice ID | 完整合成后播放 |
| Google Translate TTS | 可访问对应在线服务的网络 | 选择语言和正常 / 慢速 | 分段合成，接收并合并后播放 |

程序不会安装上述外部引擎、自动下载配音权重或把本机模型上传到远端。请按各引擎和声音的使用条件准备资源。

### 其他引擎的通用操作

1. 在“引擎与声线”页左侧选择要配置的引擎。
2. 有服务地址的引擎，填写“本地 / 默认 Base URL”；需要远程服务时，填写“远程 Base URL”并打开“使用远程实例”。两处地址分别保留。
3. 选择声音，填写该引擎实际支持的参数，再通过“试听当前引擎声音”验证。
4. 要让这个声音可以分配给角色，填写“声线名称（可选）”，点击“添加为声线”。不填写名称时，使用当前声音名称。
5. 到“角色”页完成角色或默认 NPC 的分配。仅添加为声线不会自动替换默认 NPC 或某个角色的声线。

“本引擎的声线”中可以选择已添加的声线，修改名称或声音 ID，也可以删除不再使用的声线。仍被旅行者、角色、默认 NPC 或旁白引用的声线不能直接删除，需要先解除引用。

VOICEVOX 和 VITS 的服务端声音列表需要主动点击刷新；其他引擎的本地预设或系统声音列表也可能在选择引擎、修改模型时自动加载。Google 的语言列表使用本地预设。能列出声音不等于已经验证合成，仍需试听。

#### 火山翻译

选择中文预设音色即可，不需要本地模型、账号或 Key。该功能使用非公开客户端接口，没有稳定性或限流承诺；正式配音会向该服务发送待朗读台词，试听会发送试听文本。网络错误或服务拒绝时，可以稍后重试或切换引擎。

#### Windows 系统语音（SAPI）

刷新并选择已安装的声音，速度倍率范围为 `0.5～2`。系统能够用于其他软件的某种声音，不一定已暴露为 SAPI 声音；列表为空时应检查安装与兼容性，而不是填写别人的声音标识。

#### VOICEVOX

默认本地地址为 `http://127.0.0.1:50021/`，以实际服务端口为准。刷新后选择声音 / 风格，或填写非负整数 Style ID。支持速度倍率 `0.5～2`、音高 `-0.15～0.15`。声音的使用条款与署名要求由相应声音库规定。

#### vits-simple-api

默认本地地址为 `http://127.0.0.1:23456/`。当前适配 VITS 和 BERT-VITS2 的文本合成，声音 ID 由模型类型和编号组成。根据服务要求填写可选 API Key，选择语言和 `0.5～2` 的速度倍率。

这里的语言选项控制配音服务，不会自动使游戏画面识别支持相同语言。其他 VITS 模型类型不能仅凭服务端存在就认定本客户端已经支持。

#### OpenAI 兼容语音 API

填写服务要求的完整 Base URL，保留必要的路径前缀，例如 `https://服务器/v1/`。再填写服务端当前可用的模型、Voice ID，以及服务要求的 API Key。

界面中的模型和声音示例只是输入建议，不代表服务当前支持它们；自建兼容服务可以填写自定义 ID。支持 WAV、MP3，以及按 24 kHz、单声道、16 位 PCM 解释的 PCM 响应，速度倍率范围为 `0.25～4`。地址格式检查不等于认证成功，需用试听确认。

#### Google Translate TTS

选择预设语言，速度为 `1`（正常）或 `0.5`（慢速）。这是网页 TTS 接口，不是 Google Cloud TTS 的服务承诺；需要网络可达，服务可能拒绝请求。分段接收不等于增量播放，当前仍在完整音频准备好之后播放。

## GPT-SoVITS

### 连接服务

先自行启动兼容的 GPT-SoVITS `api_v2` HTTP 服务，再在“引擎与声线”页左侧选择 GPT-SoVITS。本地默认地址为 `http://127.0.0.1:9880/`，应以实际启动参数为准。

需要远程实例时，打开“使用远程实例（本地与远程地址分别保留）”，再在“服务地址”中填写远程地址。打开或关闭这个开关时，地址框会切换显示本地或远程地址。支持带路径前缀的反向代理地址；URL 不能内嵌用户名、密码、查询令牌或片段，格式不正确时地址框下方会显示提示，原有效地址保持不变。

点击“测试连接”只检查服务可达性，不会合成台词、切换权重，也不能证明后端空闲。连接 / 请求 / 合成超时在“高级”页设置，对所有引擎生效：连接范围 `1～120` 秒，请求和合成范围 `1～600` 秒；合成默认 `180` 秒。

### 建立声线

1. 在“声线”下点击“新增”。
2. 在下拉框中选中要编辑的声线，填写便于识别的名称。修改名称不会改变角色对这条声线的引用。
3. 选择服务实例。选“跟随当前实例”时使用上面开关选择的实例；明确选择本地或远程，可以固定这条声线所使用的实例。
4. 填写 GPT 权重 `.ckpt`、SoVITS 权重 `.pth`、参考音频，以及与参考音频逐字对应的中文“参考台词”。本地实例可使用“浏览”选文件。
5. 等待窗口底部显示“已保存”。新建但资源不完整的声线会留在草稿中，不能把它当作已经保存成功。
6. 在“试听”中输入文字，点击“试听选中声线”。需要中断时点击“停止试听”。

资源只在当前选中的声线中维护。要修改某个角色的 GPT 资源，先找到它分配的声线，再到这里编辑，不需要给每个角色重复填一套权重。

本地声线的相对资源路径以角色目录 JSON 所在目录为基准。远程声线的权重、参考音频必须已经存在于服务器，填写服务器能够访问的路径；客户端不会上传文件，也不会用本机的同名路径代替服务器路径。

### 把 GPT 声线用于正式配音

新建声线后，还要完成分配：

1. 在“引擎与声线”页选中 GPT-SoVITS，点击“设为默认引擎”。
2. 在“角色”页打开“启用角色声线”。
3. 在“默认 NPC 声线”中明确选择刚建立的 GPT 声线，作为未匹配角色时的声音。
4. 按需为旅行者和已知角色选择声线，等窗口底部显示“已保存”，再关闭设置窗口。

> 只创建 GPT 声线、只设为默认引擎，或关闭角色声线，都不会自动把这条声线设为默认声音。关闭角色声线时仍沿用配置中的旧默认声音字段；新配置不一定已有这些资源。首次配置 GPT 时，请打开角色声线并明确指定默认 NPC 声线，避免出现默认资源为空的错误。

### 实验性流式配音

打开“按句流式合成与增量播放（实验性，关闭时完整合成）”，关闭设置窗口后生效。默认关闭，需要后端支持当前 `api_v2` 按句流式协议；其他引擎不会因为打开这个开关就变成流式播放。

当前 GPT 协议固定中文文本、中文参考语言、`cut5` 切分和 WAV，不提供界面未展示的语速或其他流式模式。试听始终完整接收后播放，不能用试听来证明正式流式播放正常。

完整模式会在新句音频准备好后再替换旧句；流式模式会等待新句有足够的有效音频再接替。缺料或断流时可能停止本句，已经播出的片段不能撤回，也不会自动重新合成并拼接。出现问题时，关闭流式开关，用完整模式排查。

## 角色、旅行者和默认声音

声线是“如何合成声音”的配置，角色是“识别到谁时使用哪条声线”的规则。多个角色可以共用一条声线，也可以在同一份角色目录中使用不同引擎的声线。

### 默认规则

- 关闭“启用角色声线”时，所有对白使用默认引擎的默认声音。
- 打开后，明确的角色分配优先；没有可用的专属声线并按“找不到角色声线时”的设置回退时，先使用明确指定的“默认 NPC 声线”。它可以是另一种引擎的声线，不受默认引擎选择覆盖。
- 没有明确指定默认 NPC 声线时，才使用默认引擎的默认配置。
- 下拉框中的“未单独指定（使用默认规则）”表示没有单独指定声线，不等于自动选择列表第一项。

### 旅行者

在“旅行者 → 游戏内昵称”填写画面中会出现的昵称，有多个历史昵称时一行一个；在“声线”中选择已准备好的声线。

昵称用于 OCR 匹配，不会修改游戏内名称。不要填入其他角色已有的姓名、别名或识别纠错，否则目录校验会拒绝冲突。角色列表中空、荧仍可以有各自的声线；选择旅行者的声音不等于为所有提到“旅行者”的文本自动判定性别。

### 已知角色

在角色列表上方搜索名称、别名或识别纠错。选中角色后可以编辑：

| 字段 | 作用 |
| --- | --- |
| 正式名称 | 画面中的正式姓名，一行一个，至少填写一项 |
| 别名 | 同一角色可能出现的其他名称 |
| 识别纠错 | 将确定的姓名误识别结果归到这个角色，不修改对白正文 |
| 声线 | 从已经准备好的声线中选择；未单独指定时使用默认规则 |
| 角色 ID | 角色目录内部的唯一标识，旅行者等规则引用它，一般不用改 |

使用“添加角色”添加，使用“删除”移除选中的角色。识别姓名时会依次尝试正式名称、别名和识别纠错，不会因为名称相似就随意替换角色。

“高级 → 找不到角色声线时”可以选择改用默认 NPC 声线或报错，用于已知角色没有分配声线或声线资源不可用的情况。普通 NPC 总是使用默认 NPC 声线，这不等于配置出了错；应先准备一个可用的默认 NPC 声线。

### 旁白

“旁白声线”可以保存，但当前实时对白链路尚未传入明确的旁白上下文，自动旁白路由还没有接通。不能依靠这一项让无姓名栏对白自动切换到旁白声线。

姓名 OCR 失败也不等于旁白。排查无姓名画面的声音时，先查看实际命中的声线和默认 NPC 回退，不要仅凭姓名为空判断路由结果。

## 自动保存与生效时间

设置使用自动保存，没有单独的保存按钮。打开设置窗口时自动配音暂停；关闭窗口时先保存角色目录草稿，再按新设置重新开始。

| 修改内容 | 写盘方式 | 配音何时使用 |
| --- | --- | --- |
| 默认引擎、采样间隔、连接、超时及各引擎普通参数 | 由 BetterGI 自动保存，将约 500 ms 窗口内的改动合并写入；URL 需先通过格式检查 | 关闭设置窗口后；试听立即使用 |
| 角色、旅行者昵称、默认规则、声线及资源 | 输入停顿 750 ms 后校验，只有有效草稿才会自动保存 | 关闭设置窗口后；试听使用所选引擎或当前声线草稿 |

750 ms 是安排校验和保存的防抖时间，不是写盘一定完成的时限。请以窗口底部的保存状态为准，例如“已保存 · 关闭设置窗口后生效”。切换声线、引擎或标签页不会清空输入，也不会取消已经安排的保存。

以下情况不会直接覆盖已有有效文件：

- 新声线名称、声音 ID 或引用不完整。
- 新输入的本机 GPT 权重或参考音频路径不存在。
- 角色目录文件被其他程序修改，当前草稿的版本已经过期。
- 编辑过程中更改了角色目录文件路径，当前草稿仍属于旧目标。

已保存但暂时不可用的旧资源可以保留并显示诊断，不会静默换成第一条声线。保存期间继续输入时，较新的输入会再安排一次保存。

关闭设置窗口时如果角色目录草稿无法保存，卡片会提示“角色目录有未保存的修改”，草稿保留，再次打开设置窗口可以继续修正。关闭设置窗口不会丢弃草稿。

正常关闭主窗口或从托盘退出时，程序会尝试排空角色目录草稿；草稿校验或保存失败会阻止退出，并提示修正。关闭到托盘只是隐藏窗口，不代表退出。无效 URL 只保留在编辑输入中，原有效地址仍保留，不保证阻止退出；请在关闭前修正。强制结束进程、系统强制关机或断电不能保证保存尚未完成的输入。

试听进行中时，受保护的角色和资源编辑操作会暂时禁用，试听结束后恢复。

## 角色目录文件、导入和备份

“高级 → 角色目录文件”决定当前使用的角色和声线清单，默认是程序目录下的 `User/QuestVoice/routing.json`。这里的“目录”指 JSON 清单，不是游戏目录或模型文件夹。

首次打开设置窗口时会按需准备示例；示例没有配音权重，不代表其中角色已具备专属声音。已有配置不会被示例覆盖。

路径下方的操作：

| 操作 | 行为 |
| --- | --- |
| 重新加载 | 从当前文件读取清单；有未保存的修改时，先确认是否放弃 |
| 校验 | 检查当前草稿结构、引擎和引用，不等于检查服务可达或实际完成合成 |
| 导入… | 读取选定 JSON，确认提示后，将有效内容自动保存到当前文件，并保留备份 |
| 导出… | 将通过校验的草稿写到另一个 JSON，不替代当前文件的自动保存 |
| 新建空目录 | 当前目标文件不存在时，建立空的清单草稿；有效内容仍按自动保存机制处理 |

> 导入会安排写入当前角色目录文件，不是只预览。先检查当前路径，再确认导入；需要保留现有配置时先备份。导出时也不能把目标选成当前文件。

成功保存会对原文件保留 `.bak` 备份，例如 `routing.json.bak`。这是保存时的旧文件备份，不代替用户自己的长期备份。

窗口底部出现“文件冲突”时，不要继续用旧草稿覆盖磁盘上的新配置。先导出能够通过校验的草稿，再重新加载并核对差异。准备切换角色目录文件路径时，也应先处理旧草稿；程序不会把旧输入自动写到新目标。

旧版 v1 清单可以继续读取，编辑并成功保存或导出后按 v2 写入，单纯加载不会升级。旧 v1 清单在普通引擎下沿用固定声音；需要按角色分配声线时，先完成有效编辑并保存为 v2。

## 停止与异常恢复

关闭卡片开关即可停止配音。已经发给 GPT-SoVITS 的请求可能仍需排空，期间卡片显示“停止中”；取消本地播放不等于远端推理已经结束。应用退出时会直接中止这些请求。

如果连接中断后出现“后端状态未知”，按以下顺序恢复：

1. 关闭卡片开关，等待停止完成。
2. 手动恢复或重启 GPT-SoVITS 服务，确认它已经可用。
3. 点击卡片状态行的“确认后端已重启”。
4. 打开卡片开关，自动配音重新开始。

“确认后端已重启”只在后端状态未知时显示，运行中不可点击。程序不会替你关闭或重启外部 GPT 服务；退出 BetterGI 也只关闭本地工作。

## 常见问题

| 现象 | 建议检查 |
| --- | --- |
| 实时触发页没有“自动配音”卡片 | 确认当前版本确实包含该功能，不要把其他分支的界面说明套到当前安装包 |
| 开关已打开，卡片显示“等待启动截图器” | 在启动页绑定原神并启动截图 |
| 卡片显示“独立任务运行中，已暂停” | 一条龙、JS 脚本等任务运行时会暂停配音，任务结束后自动恢复 |
| 试听正常，进游戏后没有识别 | 试听不依赖 OCR 和游戏截图；检查截图器是否已启动、游戏是否在前台、对白是否显示足够久，以及是否处于暂停热键、战斗或传送中 |
| 提示内置 OCR 初始化或推理失败 | 检查“硬件加速”设置和日志；可以先打开“OCR 使用 CPU”排除显卡或驱动问题 |
| 识别偏慢、跟不上对白 | 关闭“OCR 使用 CPU”改用显卡，或适当调大采样间隔 |
| GPT 声线能试听，正式配音却提示默认资源为空 | 检查是否打开了“启用角色声线”，以及默认 NPC 是否明确选择了已建立的 GPT 声线 |
| 改了引擎却仍用原来的声音 | 检查默认引擎的 ★ 是否已改到新引擎；已分配给角色的声线按各自的引擎播放 |
| 角色没有使用专属声线 | 检查“启用角色声线”、识别到的姓名、正式名称 / 别名 / 识别纠错、声线分配、“找不到角色声线时”的设置，以及修改是否已保存 |
| 无姓名画面没有使用旁白声线 | 当前实时管线尚未接通自动旁白路由；先查看默认 NPC 回退和实际路由结果 |
| 窗口底部一直显示“等待输入有效配置” | 检查所有未完成的声线、名称、声音 ID、引用及新填写的本机路径，不要把停顿 750 ms 当作必然保存成功 |
| 提示文件冲突或路径已改变 | 导出有效草稿，重新加载对应文件并核对；不要直接覆盖他人的修改 |
| URL 输入没有保存 | 使用完整 HTTP/HTTPS 地址，保留服务要求的子路径，不要在 URL 中加入账号、密码、查询令牌或片段 |
| 在线引擎出现 TLS、超时、认证或限流错误 | 检查网络、服务地址及凭据；连接检测不等于合成成功。不要通过关闭证书校验来处理，可先换用本机系统语音排除网络因素 |
| 画面已换句，仍能听到上一句 | 新句在音频准备好后才接替，旧句可能继续播放；需要立即中止时关闭开关 |
| 设置窗口中部分控件无法编辑 | 试听进行中时会暂时禁用，等试听结束或点击“停止试听” |

## 配置文件

以下路径均相对于 BetterGI 程序目录；修改过角色目录文件路径时，以实际设置为准。

| 路径 | 内容 |
| --- | --- |
| `User/config.json` | 开关、默认引擎、采样间隔、连接、超时及各引擎参数；可能包含本机路径、API Key 等私密信息 |
| `User/QuestVoice/routing.json` | 角色、昵称、默认规则和声线；可能引用本机或服务器上的权重与参考音频 |
| `User/QuestVoice/routing.json.bak` | 角色目录的旧内容备份，同样需要按私人配置处理 |
| `User/QuestVoice/auto-scene.json` | 按需部署的对白场景资源，不熟悉格式时不要随意改动 |
| `User/QuestVoice/cache/` | 每轮配音的临时音频，正常停止后清理；异常退出可能留下文件 |
| `log/` | BetterGI 主日志，可能包含对白、识别结果、资源路径和错误信息 |

Key 在界面中遮罩显示，不代表配置文件已经加密。不要直接上传整个 `User` 目录、备份、参考录音或日志；反馈问题前先脱敏。使用在线引擎时，待合成文本会发送到相应服务；使用他人提供的模型、角色声音或服务时，应遵守相应使用条件。
