# 文档

仓库文档按主题分类存放。

```
Docs/
├─ architecture/       # 架构设计
├─ development/        # 开发者文档
├─ technical/          # 具体技术实现
├─ api/                # API / SDK
├─ design/             # 设计文档 / ADR
├─ images/             # 文档图片
├─ archive/            # 废弃/历史方案
├─ tmp/                # AI 临时设计文件（git 忽略）
└─ i18n/               # README 多语言文本
```

| 目录 | 用途 |
| --- | --- |
| [architecture](architecture/) | 整体架构、分层、模块边界与演进方案 |
| [development](development/) | 编译、调试、贡献流程等开发者文档 |
| [technical](technical/) | 具体功能或子系统的技术实现说明 |
| [api](api/) | 对外或对内的 API / SDK 说明 |
| [design](design/) | 设计文档与架构决策记录（ADR） |
| [images](images/) | 文档引用的图片资源 |
| [archive](archive/) | 已废弃或仅作历史参考的方案 |
| [tmp](tmp/) | AI 临时设计文件，内容不提交 |
| [i18n](i18n/) | 根目录 README 的多语言文本 |
