# BetterGI 领域术语

> 归档于 2026-10-24：精简前的根目录 `CONTEXT.md`（含体力计划术语与“开发工作目录”等已删除条目），当前术语见 [CONTEXT.md](../../../../CONTEXT.md)。以下为原文，不代表当前实现；只修正了相对链接的路径。

本词汇表记录 BetterGI 中已经明确的领域概念。Pulonia 从本机仓库副本或本地仓库读取资源，并由任务计划显式决定何时采用新内容；本地开发来源管理与调试体验仍属于后续设计。

## Language

### Pulonia 任务与资源

**任务计划**：用户组织的一棵任务树，描述执行顺序、任务参数和引用关系。
_Avoid_：把脚本仓库称为任务计划。

**任务触发器**：任务计划的发起规则，表达用户选择的运行日程或快捷键。
_Avoid_：把任务何时发起与游戏资源何时刷新混为一谈。

**文件级采集 CD**：以一份地图追踪路线完整执行成功估算该路线的采集完成，再按对应材料的刷新规则判断何时可以重跑。失败不记录路线内的部分采集；同种材料的不同路线各自计时。
_Avoid_：把同一种材料的全部路线视为同一个冷却对象，或把路线完整执行当作逐点拾取核验。

**路线执行结果**：一条路线本次执行的成功状态、已知失败原因及已观测统计。成功表示整份路线文件被成功执行；拾取内容、复活次数等尚未统计时属于未知，不能解释为零。
_Avoid_：把正常返回解释为路线成功，或把未统计的拾取明细解释为没有拾取。

**脚本仓库**：一组具有明确来源和管理边界的脚本资源，可以包含 JS 项目、路线等不同资源类型。
_Avoid_：用“当前仓库”表示所有任务唯一可用的来源。

**仓库注册**：Pulonia 已经接纳并保存身份的脚本资源来源；只有添加成功后才成为可选择的仓库，未完成的添加草稿不是仓库注册。
_Avoid_：把仓库注册称为仓库订阅，或把注册仓库等同于同步内容。

**远程仓库**：资源由远程发布方提供、用户可以获取其更新的脚本仓库；官方与第三方描述发布方身份。
_Avoid_：把官方与远程、第三方与本地当作同一分类。

**本机仓库副本**：程序从远程仓库同步到本机、供资源浏览和更新检查使用的仓库内容；它是传输与读取边界，不是任务实际使用版本。
_Avoid_：把本机仓库副本称为本地仓库，或认为同步副本会自动改变任务。

**本地仓库**：内容由用户在本机维护的脚本资源集合，不由远程仓库更新流程维护。
_Avoid_：把远程资源在本机的下载副本称为本地仓库。

**开发工作目录**：开发者直接编辑与调试脚本的本地仓库；即使它关联 Git 远程地址，其内容仍由开发者维护。

**仓库订阅**：老配置组选择资源并安装到旧用户脚本目录的兼容机制，不属于 Pulonia 的仓库使用流程。
_Avoid_：在 Pulonia 中用“订阅”表示注册仓库、同步仓库或更新任务资源。

**同步仓库**：把远程仓库内容同步到本机仓库副本；只改变本机可浏览的来源，不改变任何任务计划使用的资源。
_Avoid_：把同步仓库描述为更新任务。

**刷新本地仓库**：重新读取用户维护的本地仓库内容，使 Pulonia 能检查其当前资源；不访问远端。

**更新任务资源**：任务计划显式采用本机仓库副本或本地仓库中的当前资源，并保留新的任务使用版本。
_Avoid_：把更新任务资源与同步远程仓库混成同一个不可区分的动作。

**任务资源引用**：任务对某个仓库中具体脚本资源的引用，表达仓库身份、资源位置和已确认的仓库版本。
_Avoid_：用显示名称区分来自不同仓库的同名脚本。

**资源版本**：一份确定的脚本资源内容；同一资源的不同版本仍属于同一来源。
_Avoid_：把资源版本与仓库身份混用。

**声明版本号**：脚本或路线正文声明的、面向用户展示的版本文字；它可以缺失或未随内容更新，不能替代资源指纹判断更新。

**任务使用版本**：任务已经确认并保留、后续运行实际读取的资源版本；来源内容变化不会自动替换它。

**资源指纹**：判断计划资源是否有更新的内容摘要。路线比较 JSON 正文；JS 仅比较 `main.js` 和 `manifest.json`，不代表完整项目或依赖的仓库版本。

**已确认内容**：计划或运行已经明确采用并保留的来源版本；仓库拉取更新不改变这份内容。

**脚本工作目录**：从已确认内容准备的可写运行副本，保存脚本声明的用户数据；按仓库与脚本共享进度，不承担版本缓存的职责。

### Pulonia 培养与树脂

**一条龙**：通过专用界面编辑和执行的一类任务计划，与普通任务计划共享任务及其执行含义。
_Avoid_：把一条龙当作另一套任务系统。

**体力计划**：属于某个账号的具名培养方案，包含近期培养目标、培养方面优先级、最终兜底和资源偏好；同一账号可以保存多套方案。
_Avoid_：把体力计划与任务计划混用，或把体力计划称为树脂使用顺序。

**培养目标**：为角色、武器或天赋达到指定程度而准备的有限材料需求。
_Avoid_：把材料备齐等同于角色已经升级或实际达标。

**培养方面优先级**：等级突破、武器、关键天赋等培养方面的预算分配顺序；角色培养默认同级。
_Avoid_：把培养方面的优先级当作角色排名或任务树执行顺序。

**绑定体力计划**：任务计划引用一份体力计划，供其中明确选择跟随的字段使用。
_Avoid_：把绑定理解为自动接管所有任务或自动生成任务计划。

**跟随体力计划**：任务的某项字段选择由体力计划计算；对象选择与树脂使用可以分别选择来源。
_Avoid_：把单个字段的跟随扩展为整个任务或全部配置的自动覆盖。

**执行段**：一个已有任务内部连续执行的一批操作，归属于原任务的本次执行内容。
_Avoid_：把执行段当成新增的任务计划节点。

**树脂预算**：本次允许使用及已经预留的各类树脂资源，资源类型和用途限制各自保留。
_Avoid_：把所有树脂折合为可以互相替代的一份总量。

**最终兜底**：有限培养需求安排完成后使用剩余资源执行的内容，也可以选择保留树脂。
_Avoid_：让长期圣遗物刷取成为其他有限培养目标的前置条件。

**体力预计算**：根据体力计划、任务配置和已观测状态计算出的本次预计安排，包含对象、次数、资源用法及原因。
_Avoid_：把预计次数当作已确认产出，或把旧观测当作当前库存。

**无状态培养规划**：每次根据实际练度和库存重新计算培养需求，不使用跨次刷取次数、完成标记或角色轮转游标推算进度。
_Avoid_：把无状态理解为不保存用户方案，或不保留单次运行记录。

### 多实例协作

**主实例**：同一 Windows 用户下统管子实例的 BetterGI，负责统一安排任务，也可以在自己的游戏环境中执行任务。
_Avoid_：把主实例理解为只能管理、不能执行的控制面板；“根实例”是同一角色的既有称呼。

**子实例**：接受主实例控制、提供独立执行环境的 BetterGI，包含桌面分身和云原神网页版实例两种角色。
_Avoid_：把子实例仅指向桌面分身，或认为子实例各自拥有独立的 Pulonia 调度权。

**桌面分身**：运行在另一 Windows 会话中的子实例，提供该桌面内的游戏操作和本地界面。
_Avoid_：把桌面分身当作另一个主管全部实例的主实例。

**云原神网页版实例**：以一个具名云原神网页环境为执行对象的子实例，提供该环境的游戏画面和自动化执行。
_Avoid_：把它当作只能显示网页、不能执行任务的窗口。

**执行目标**：一次任务请求选定的执行实例，决定实际操作哪一个游戏环境；选择子实例不转移主实例的编排职责。

**共享配置**：同一套 BetterGI 实例共同使用的持久化设置；各实例可以暂时使用不同时间读取的内容，不承诺修改后立即处处一致。
_Avoid_：把共享配置理解为共享运行状态，或把共享文件理解为跨实例实时同步。

### 外部访问

**外部访问能力**：BetterGI 明确提供给调用方使用的一项稳定功能，独立于 HTTP、MCP 等传输方式。
_Avoid_：把同一功能在不同协议中的入口当作彼此独立的能力。

**外部访问服务**：BetterGI 向本机调用方提供外部访问能力和实时信息的应用边界。
_Avoid_：把它理解为面向局域网或公网的远程管理服务。

**外部调用方**：通过外部访问服务使用 BetterGI 能力的本机程序、页面或工具。
_Avoid_：默认认为调用方属于 BetterGI 主进程内部组件。
