# 步骤 7：触发器、Cron 与空闲准入验收

入口：**任务计划 → 选择计划 → 触发方式**。新配置默认禁用，表单草稿只有点击“保存触发器”后才保存到 `User/Pulonia/plans/<planId>.json`。调度游标、等待状态和排队请求保存在同一 `User/Pulonia/state.json`，运行历史仍在 `history/<planId>/<runId>.json`。执行记录详情可查看触发器 ID、范围、发生时间和最晚开始时间。

## 表单与持久化

1. 建立只有 `sample.sum` 的纯 C# 计划（`values` 为 `[1,2,3]`）。新增定时触发，选择“每日 04:00”，确认表达式为 `0 4 * * *`，五次预览按所选时区显示。
2. 选择“每周一 04:00”，修改星期为周三、时间为 17:15，确认 `15 17 * * 3`；进入高级模式应保留此表达式，而不是跳回每日默认值。
3. 验证每月 31 日跳过短月份；一次性日程展示所选日期；20/24/48/72 小时选项改为固定间隔，修改起算点后重启，计时不能重置。只改名称不能丢失原锚点秒数。
4. 高级 Cron 输入 `0 4,20 * * *` 应显示每天两个时刻；`0 0 4 * * *`、`*/0`、`?`、`L` 或小时 25 应显示错误且不能保存。日和星期同时限制时取交集，界面有说明。
5. 使用 UTC+8/+1/-5 快选及其他时区，核对预览的日期和偏移。日程时区并不自动修改执行器的服务器 CD 账本规则。每天不同分钟的多个时刻可创建多个触发器。
6. 选择一个分组/叶子为范围，保存并启用，确认仅该子树执行且祖先禁用和策略仍生效。范围外缺失资源不会阻塞资源准备。删除或禁用触发器不删除历史；删除可由计划撤销恢复。

## 到期、忙碌与用户活动

1. 将日程设为几分钟后的时间，开启空闲条件。持续操作电脑时显示等待空闲，无游戏输入租约；空闲达到阈值且仍在有效窗口内才提交。
2. 缩短窗口并持续操作直到超过窗口，应显示过期、不启动任务；关闭补触发后，离线错过的时间不补。离线多日并开启补触发，只合并有效窗口内最新一次。
3. 同一计划添加可延时的 `sample.sum`（`delay_milliseconds`），分别验证“跳过/合并”和“再排一次”，不能无界积累。不同计划串行排队。
4. “停止当前”启用前须确认；触发后旧任务先退出和释放资源，新请求才能开始，不能两边同时输入。等待清理时连续触发也只保留一个同计划候选。
5. 请求排队后禁用、删除或调整触发器，旧签名请求开始前应取消；排队超出最晚开始时应进入“已过期（未执行）”历史，开始时间为空，没有节点执行结果。
6. 开启“用户回来取消”，运行时移动鼠标或按键，新增输入被拒绝，抬键清理仍执行；纯 C# 延时任务同样取消。历史显示用户活动/桌面不可用的原因，而非宣称无损暂停。
7. 本程序自身带标记输入不重置空闲；其他程序注入输入计作活动。无法确认桌面/输入检测状态时保守等待。锁屏不操作游戏；解锁后重新累计空闲。

## 热键与 Windows 唤起

1. 新增全局热键，用捕获框输入 `Ctrl + Alt + F8`，保存并启用。热键默认不要求空闲，也不因松开热键取消；可以自行调整。重复按键由系统无重复注册、1 秒防抖和忙碌策略合并。
2. 与现有快捷键或另一个触发器冲突时，下方显示注册失败，不偷偷占用。修改后保存可重新注册。仅主实例注册，子实例不重复执行。
3. 勾选 Windows 唤起并保存，系统任务名为本安装/当前用户独占的 `BetterGI-Pulonia-<摘要>`。仅管理该任务，不修改用户其他任务；保存最高可用权限登记失败时明确显示错误，程序内调度仍有效。
4. 系统任务执行 `BetterGI.exe --pulonia-dispatch`；已有主实例时经现有 IPC 转发，不能激活主窗口抢用户焦点。未启动时在已登录交互会话启动并检查准入，不自动从旧主页启动截图器。
5. `BetterGI.exe --pulonia-run <planId>` 只接受稳定计划 ID，以手动 CLI 来源提交并固定快照；无额外账号切换。游戏环境只由具体游戏节点按需准备。
6. Windows 睡眠唤醒为单独可选项，效果还取决于设备和系统电源设置。关机、未登录、锁屏均不承诺游戏自动运行。关闭全部 Windows 唤起选项后撤销本安装拥有的系统任务。从未启用 Windows 唤起、重复撤销或用户已手动删除该任务时，不应显示唤起注册失败；权限不足等真正失败仍应报告。

## 自动检查

```powershell
dotnet build BetterGenshinImpact.sln -c Debug
dotnet test Test/BetterGenshinImpact.UnitTest/BetterGenshinImpact.UnitTest.csproj -c Debug --filter FullyQualifiedName~Pulonia
```

`PuloniaTaskTriggerTests` 使用独占临时目录、受控 UTC 时钟和空闲检测替身，覆盖日周月 Cron、严格方言拒绝、DST 缺失/重复、间隔持久锚点、表单预览、重启/回拨去重、空闲等待、合并补触发、排队复核、子树准备、输入安全门及系统任务 XML。测试不启动真实应用/游戏、不调用真实任务计划注册；平台交互仍需上述人工验收。

`PuloniaWindowsTaskSchedulerTests` 通过删除操作替身覆盖正常删除、`FileNotFoundException` / `COMException` 的任务不存在映射、重复撤销，以及权限/服务/路径故障与非预期 I/O 异常的继续上报，不修改真实 Windows 系统任务。
