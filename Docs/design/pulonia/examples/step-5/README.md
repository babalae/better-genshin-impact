# 步骤 5：任务库与创建体验验收说明

[返回开发计划](../../development-plan.md) · [添加体验设计](../../user-interface.md)

本步骤不要求启动游戏。请从主菜单“自动化 → 任务计划”和“自动化 → 任务库”验收配置体验、资源索引与版本保护；真实路线、JS 和录制执行结果仍按步骤 4 的分类样例验收。

## 1. 创建前配置

1. 在任务计划的树空白处或节点上打开右键菜单，分别选择路线、JS、录制回放、Shell、C# 和内置任务。
2. 核对任务树在弹窗确认前没有新增节点；不同类型展示对应资源选择和参数字段，内置任务可先选择具体能力。
3. 修改名称和参数后确认，核对只新增一次；再次打开并取消，核对树和撤销历史没有变化。
4. 新增分组，核对必须先输入名称，取消不创建“新分组”占位项。

## 2. 单资源与预览

1. 在路线或录制弹窗搜索部分名称或相对路径，连续输入时列表应在短暂停顿后刷新，界面不应逐键卡顿。
2. 组合切换任务类型分类和一级目录范围，核对可按仓库已有的材料/目标目录收窄列表；再选择单个文件，核对详情只展示轻量摘要。
3. 选择 JS 项目，核对名称、作者、版本、说明与 README 按需出现；搜索相同资源并选择目标计划，点击“配置并添加到计划”，确认后应跳回任务计划且节点只出现一次。

## 3. 整个目录

1. 选择包含子目录的路线或录制目录，先用默认“引用目录”添加，核对树中只有一个引用组且来源包含固定版本。
2. 分别用“展开为任务并保留目录”和“展开为扁平任务”添加同一目录，核对前者保留子目录分组、后者全部放在一个分组中，文件总数一致。
3. 取消“包含子目录”后再次添加，核对只包含所选目录的直属 JSON 文件。
4. 整批添加应只产生一次可撤销编辑；执行一次撤销，整组内容应同时消失。

## 4. 资源版本保护

1. 添加一个单文件任务或目录引用并保存计划，记下右侧展示的固定资源版本。
2. 修改对应资源内容后尝试运行计划，核对应提示资源与固定版本不一致，不能静默执行新内容。
3. 在节点右键选择“确认并更新资源版本…”，核对弹窗同时展示旧、新指纹；取消时计划不变，确认后版本更新并自动保存。

## 5. 原工具入口

1. 从任务库顶部依次打开“路线录制与编辑”“JS 工具”“录制回放工具”，核对能进入原有有效页面。
2. 打开“资源来源与下载”，核对可使用现有来源更新、在线下载与离线导入；关闭窗口并刷新任务库后，新安装资源应出现在索引中。

## 6. 大目录边界

使用接近一万项的固定测试目录检查首次索引、搜索和整目录添加。列表滚动应保持可响应；索引超过安全上限时必须显示截断提示，确认整目录添加若超过上限必须整体失败，不能生成不完整任务树。
