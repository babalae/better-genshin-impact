# 高容错自动配队说明

生成日期：2026-07-01

配队原则：盾位刚需；其余三格按 `主 C（可后台）+ 副 C（可后台）+ 万叶/琴/治疗或后台输出` 组合。精英怪、大地图拾取优先带万叶；小怪、副本、不需要拾取时可以把万叶换成奶妈或后台输出。

七元素映射顺序：矿物,火,水,风,雷,草,冰,岩

- 矿物：钟纳娜万 = 钟离 / 纳西妲 / 娜维娅 / 枫原万叶
- 火：钟班香万 = 钟离 / 班尼特 / 香菱 / 枫原万叶
- 水：钟心那万 = 钟离 / 珊瑚宫心海 / 那维莱特 / 枫原万叶
- 风：钟芙琴万 = 钟离 / 芙宁娜 / 琴 / 枫原万叶
- 雷：钟纳久万 = 钟离 / 纳西妲 / 久岐忍 / 枫原万叶
- 草：钟心纳久 = 钟离 / 珊瑚宫心海 / 纳西妲 / 久岐忍
- 冰：钟迪绫万 = 钟离 / 迪奥娜 / 神里绫华 / 枫原万叶
- 岩：钟心娜万 = 钟离 / 珊瑚宫心海 / 娜维娅 / 枫原万叶

大世界推荐：

- 默认主力：钟心那万，盾奶齐全，那维莱特负责稳定清怪。
- 反制水/冰/盾怪：钟班香万，班尼特治疗，香菱火后台。
- 草/雷大地图：钟纳久万，钟离盾 + 久岐忍治疗 + 纳西妲后台草 + 万叶拾取。
- 草系副本/小怪：钟心纳久，放弃万叶换心海，盾 + 双治疗 + 超绽放更稳。

战斗策略配置使用 BetterGI 原生的 `根据队伍自动选择`。不要再使用旧的 `00-高容错七元素总策略`：总策略会让同名角色在不同队伍段落里重复命中，容易乱轴。当前每个队伍都有独立 `00-队伍名.txt` 文件，BetterGI 会按当前四人队伍精确匹配。

排轴依据：

- 钟离：长 E 护盾持续 20s，长 E CD 12s。
- 心海：水母持续 12s，E CD 20s；Q 会刷新场上水母持续时间。
- 那维莱特：E CD 12s，Q CD 18s。
- 万叶：短 E 6s、长 E 9s，Q 持续 8s、CD 15s。
- 芙宁娜：E 持续 30s、CD 20s，Q 持续 18s、CD 15s。
- 纳西妲：标记持续 25s，短 E 5s、长 E 6s，Q 基础持续 15s、CD 13.5s。
- 久岐忍：E 环持续 12s，CD 15s。
- 班尼特：短 E 5s，Q 持续 12s、CD 15s。
- 香菱：锅巴持续 7s、CD 12s，Q 持续 10s、CD 20s。
- 迪奥娜：长 E CD 15s，护盾按命中爪数计约 12s；Q 持续 12s、CD 20s。
- 神里绫华：E CD 10s，Q 持续 5s、CD 20s。
- 娜维娅：E 单层 CD 9s、两层充能，Q CD 15s。

策略写法：

- 所有默认队伍采用长短轴：短轴建立后台/爆发，长轴中间插入钟离补盾，后半段只刷需要刷新的角色，不强制每段切满四人。
- 相邻两次钟离盾之间的显式动作控制在 20s 护盾持续时间内，并额外给 Q 动画、切人和识别留余量。
- 钟离只上盾，不在默认轴中放 Q；万叶短轴只长 E 聚怪/拾取，长轴在 E 后通过 `check` 确认未结束时适度补 Q。
- 盾位先手；钟离用 `e(hold,wait)` 等盾，其他非盾位 E 默认不等 CD，避免心海/班尼特/香菱/万叶把轴卡死。
- Q 不使用裸 `q`，改成多次 `keypress(q)` 补按后再 `ready/check`，降低班尼特、香菱等漏 Q。
- 策略文件不再使用 `click(middle)`，避免和 BetterGI 的“旋转寻找敌人/尝试面向敌人”互相打架。
- 纳西妲长 E 使用 `keydown(e) + moveby(...) + keyup(e)` 扫描标记多目标。
- `钟心那万` 在第一次那维莱特长喷后立即插入心海 Q 刷新水母，再补钟离盾进入后续长轴。
- 那维莱特输出段在 E/Q 后连续按住左键，先等待充能/吸水完成，再进入多方向 `moveby(...)` 横扫，减少 E 后只转圈不喷水、喷射覆盖不足和散怪漏打。

400 精英脚本组说明：

- `自动化一条龙` 与 `每天4点10-自动化总控` 中的脚本组级自动战斗 `timeout` 仍保持 `200`，避免影响同组的小怪、蕈兽、发条机关等非 400 路线。
- 当地图追踪任务来源路径匹配 `精英400@汐` 或 `400精英` 时，程序会在执行该路线的 `fight` 动作时临时禁用时间型战斗超时；正常结束仍依赖战斗结束检测，找敌失败保护仍保留。

注意：这些文件只负责 BetterGI 队伍名和战斗策略；游戏内队伍预设仍需要存在同名队伍。已同步更新 `手动-配置自动化队伍` 脚本组，可运行一次自动配置这些队伍。
